### 现在武器的三个模式已基本实现

- 日常模式🍃：造成10%攻击对象最大生命伤害
- 横扫模式📚：对周围的敌对生物造成100点虚空伤害
- 幻梦异曲🖼️：造成超高的伤害，极致的数值

> **关于横扫模式**：现在，横扫模式不会主动攻击友善生物。但在横扫模式下主动攻击友善生物会挂上 _**标记**_
> 被标记的生物可以在手持这把剑时右键以触发伤害
